مدرستي — إصدار الوضعين (أونلاين + محلي)

الملفات:
- index.html: واجهة المنصة
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت
- sw.js: تخزين واجهة الموقع ومكتباتها للعمل دون اتصال بعد زيارتها
- icon.svg و icon-192.png و icon-512.png: أيقونات التطبيق

طريقة النشر على GitHub Pages:
1) فك ضغط الحزمة.
2) ارفع الملفات الأربعة إلى جذر مستودع GitHub.
3) من Settings > Pages اختر Deploy from a branch، ثم main و /(root).
4) افتح رابط HTTPS الناتج بمتصفح Chrome على الهاتف.
5) بعد أول فتح انتظر تحديث الصفحة التلقائي مرة واحدة حتى يشتغل التخزين دون إنترنت.
6) من قائمة المتصفح اختر Install app أو Add to Home screen.

الوضع الأونلاين:
- يستخدم Vireonix API على https://vireonix.ai/v1/chat/completions
- لا يحتاج مفتاح API ولا حساباً بحسب وثائق الخدمة.
- يجب وجود إنترنت. الحدود المجانية محسوبة حسب عنوان IP وقد تتغير أو تتوقف الخدمة.
- قبل الاستخدام يظهر تنبيه وموافقة لأن نص الدرس والأسئلة تُرسل إلى خدمة خارجية. سياسة Vireonix تقول إنها قد تحتفظ بالمحادثات وتستخدمها لتدريب وتحسين النماذج. لا تدخل بيانات شخصية أو خاصة.

الوضع المحلي دون إنترنت:
1) افتح الموقع أول مرة وأنت متصل بالإنترنت، وانتظر إعادة التحميل التلقائية التي تفعّل التخزين.
2) اختر «تنزيل وتشغيل بدون إنترنت» ثم اضغط «تنزيل النموذج وتشغيله».
3) اترك الصفحة مفتوحة إلى أن يكتمل تنزيل Qwen 0.5B (حجم تقريبي 483MB).
4) بعد ظهور رسالة اكتمال التنزيل، اختر الوضع المحلي. يستخدم Transformers.js ذاكرة Cache في المتصفح، ويطلب الموقع تثبيت التخزين لتقليل احتمالية حذف الملفات.
5) بعد تنزيل النموذج وتخزين واجهة الموقع ومكتبات التشغيل، يمكن فتح التطبيق واستخدامه محلياً دون إرسال الأسئلة إلى خادم الذكاء الاصطناعي.

ملاحظات مهمة:
- التنزيل الأول يتطلب الإنترنت ويدعم WebGPU؛ بعض الهواتف/المتصفحات لا تدعم ذلك.
- لا يمكن ضمان احتفاظ المتصفح بالملفات إلى الأبد؛ قد يحذفها النظام عند نقص المساحة أو مسح بيانات المتصفح.
- لا تفتح ملف index.html من مدير التنزيلات content://؛ هذا لا يسمح بتسجيل Service Worker أو تخزين تطبيق PWA بشكل موثوق. استخدم HTTPS.
- PDF.js ومكتبة Transformers.js تُخزنان بعد تحميلهما أول مرة عبر Service Worker، وملفات النموذج تُخزن في Browser Cache الخاصة بـ Transformers.js.
- لم يتم اختبار اتصال API الفعلي من هاتف المستخدم؛ إذا منع المتصفح الاتصال أو ظهرت حدود الاستخدام، استخدم الوضع المحلي. الخدمة الخارجية يمكنها تغيير سياساتها أو توفرها.
